# 二维概率栅格建图实验平台

**真实数据模式**：安装 `python -m pip install pyserial`，启动 `python run_demo.py`，点击“真实数据建图”，刷新并选择瑞萨调试串口（921600、8N1），关闭其他占用该串口的软件后点击连接。连接后重启瑞萨板以从第一帧开始同步；遥控器仍独立控制小车。红点和箭头表示雷达参考点位姿，灰色未知、白色空闲、黑色占据。状态栏显示序号间断和 CRC 错误；如果没有从首帧开始或中途丢帧，电脑地图与板端可能不同，需重启板子重新开始。按钮“清空电脑地图”不会清空板端地图。

真实模式使用瑞萨 `4.LSLidar-stm32/src/Algorithm/map_core.c` 相同源码和板端已计算的雷达位姿、射线，数据帧以 `A5 5A` 开头，长度为小端 uint16，负载为帧号 uint32、x/y/heading float32、射线数量 uint8 和每条 angle/distance float32，末尾 CRC-16/MODBUS（覆盖长度和负载，小端）。数据以二进制发送，不再是旧的文本调试格式。时间对齐仍采用板端当前的最新位姿近似；实机尚需检查角度方向和安装偏移。

在 Windows PowerShell 中进入本目录，运行 `python run_demo.py`。首次启动或 C 源码变化后会自动使用 GCC + Ninja 构建 DLL；需要 Python 的 NumPy、Matplotlib、Tkinter，及 PATH 中的 gcc、cmake、ninja。若 build 曾由其他生成器生成，请删除本目录的 build 再启动。

- **障碍物编辑**：左图拖拽画矩形。选择“选择/移动”后拖动物体；“编辑选中”输入 x,y,长,宽（米）；也可删除或清空。外墙固定管理。
- **航点编辑**：依次点击左图添加 P0、P1…；选择/移动模式可拖动、删除或用前移/后移改变顺序。勾选闭环使末点连接起点。红线代表考虑车体半径后的碰撞，不能启动。
- **监控**：点击中间地图添加监控点，右侧可滚动列表显示该格状态，下面单独显示历史曲线；点击曲线图例切换显示。清空监控可重新选择。未知格不是已观测的 50%。
- **仿真**：开始/继续、暂停、前进/后退一帧、重置；进度条选择历史扫描帧。修改场景会重置仿真。默认场景可直接开始。
- **保存/加载**：JSON 保存完整场景、运动、传感器、地图与监控配置；保存路径限定于本目录。参数按钮打开分类表单，例如在“里程计”中将“距离比例”改为 `0.85`。应用参数会重置当前仿真；修改地图几何参数会清空监控点。尺度误差作用于里程增量；航向偏差单位 rad/s。
- **导出**：可勾选导出内容，每次在 `exports` 下新建独立文件夹；地图对应当前显示帧，扫描、轨迹和监控曲线截至当前显示帧。导出说明 JSON 记录帧号和数据范围，避免误认为包含后续帧。

地图由独立 C 核心计算；Python 仅提供传感器、位姿、交互和可视化。每个扫描帧以同一姿态处理，单帧同一格至多更新一次，命中优先。碰撞采用车体圆的保守包围检测。无回波射线沿最大量程更新空闲空间。地图使用 float Log-Odds；移植时保留 `core/map_core.c`、`core/map_core.h` 的结构体和接口，按目标平台调整导出宏、内存分配及数学库。

限制：传感器为理想二维几何模型；无运动畸变、轮滑、IMU 动态、自动避障或 scan matching。旋转和直线运动是简化差速模型。每扫描帧保存完整地图以支持精确回放，长时间或闭环运行会持续消耗内存。性能和界面速度依赖电脑绘图负载。外墙固定为 5×5 m。播放速度受绘图和扫描运算性能限制。随机种子固定可复现实验。

验证：`ctest --test-dir build --output-on-failure`；`python -m unittest discover -s tests -p 'test_*.py' -v`；`python -m tests.ui_smoke`（需要图形桌面）。

播放回归测试：`python -m tests.ui_playback`（需要图形桌面）。
